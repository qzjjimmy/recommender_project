# 目录规范

## 目录职责

| 目录 | 职责 | 说明 |
|------|------|------|
| `config/` | 全局配置 | 路径、超参、设备选择，所有模块从此读取配置 |
| `data/` | 原始数据 | 知识库文档（PDF/TXT）放这里 |
| `models/` | 预训练模型 | 下载的模型文件存放位置，不纳入 Git |
| `scripts/` | 入口脚本 | 薄封装层，读配置→调src模块→写产物 |
| `src/` | 核心模块 | 所有业务逻辑实现在此，模块间可互相import |
| `outputs/` | 输出产物 | WAV/MP3/JPG/CSV/日志等运行输出 |

## 命名规范

- 模块文件：小写下划线（`audio_capture.py`）
- 类名：大驼峰（`AudioCapture`）
- 函数/变量：小写下划线（`read_chunk`, `sample_rate`）
- 常量：全大写下划线（`SAMPLE_RATE`, `MAX_TOKENS`）
- 种子：固定 `SEED = 42`

## 禁止事项

- 禁止在 `src/` 模块中硬编码文件路径（使用 `config/settings.py` 中的 `PATHS`）
- 禁止在子线程中直接操作 UI 组件（使用 `bridge.py` 中的信号）
- 禁止在 `scripts/` 中编写业务逻辑（脚本只做读配置→调模块→写产物）
- 禁止删除或修改模块的函数签名（但鼓励在现有签名基础上添加辅助方法）
